# CMS V2 后端重建阶段计划

本文档记录 CMS V2 后端重建的大致阶段。当前策略是在本仓库中新建 `src-v2/` 与 `WordSolution.CmsV2.sln`，保留旧代码和 VSTO，不在旧项目中增删改主线功能。

## 总原则

- V2 后端独立于旧后端模型。
- VSTO 暂不重写、暂不修改。
- 旧前端暂不修改。
- 旧项目保留，可作为参考，但不作为 V2 主线承载位置。
- V2 使用 .NET 10。
- V2 使用全新 SQLite 数据库 `cms-v2.db`。
- 旧业务数据视为可抛弃，不做旧数据迁移。

## 阶段 1：项目结构

状态：Done

目标：

- 建立 `WordSolution.CmsV2.sln`。
- 建立 `src-v2/`。
- 建立 Domain / Application / Infrastructure / Api / Tests 五个项目。
- 建立项目引用关系。
- 建立 `docs/cms-v2/` 文档目录。

不做：

- 不写业务代码。
- 不改旧 solution。
- 不改 VSTO。
- 不改旧前端。

## 阶段 2：Domain 领域模型

状态：Done

目标：

- 建立 17 个领域实体。
- 建立领域枚举。
- 建立 `DomainException`。
- 建立最小领域规则。
- 建立领域测试。

重点规则：

## 阶段 6：文件资产与 DOCX 核心处理能力

状态：Done

目标：

- 建立 V2 独立文件资产目录。
- 支持内容块版本 DOCX 写入与读取。
- 支持创建空白内容块 DOCX。
- 支持 HTML 预览生成。
- 支持 PlainText 提取并回写到 `ContentBlockVersion.PlainText`。
- 支持创建空白内容块文档和导入 DOCX 新版本的 Application 用例。

已完成：

- Domain 层新增 `ICmsV2FileAssetPathProvider`。
- Domain 层新增 `IContentBlockFileStore`。
- Domain 层新增 `IContentBlockDocumentProcessor`。
- Infrastructure 层新增 `CmsV2FileAssetPathProvider`。
- Infrastructure 层新增 `LocalContentBlockFileStore`。
- Infrastructure 层新增 `AsposeContentBlockDocumentProcessor`。
- Infrastructure 层引用仓库内 `lib/Aspose.Words.dll`。
- Infrastructure 层补齐 Aspose 运行时依赖 `SkiaSharp` 与 `SkiaSharp.NativeAssets.Win32`。
- Application 层新增 `ContentBlockDocumentUseCases`。
- Application 层新增创建空白内容块文档命令。
- Application 层新增导入 DOCX 新版本命令。
- 文件处理失败时应用异常统一为 `CmsV2ApplicationException`。
- 文件处理失败时尽量清理本轮已生成文件。

V2 文件目录：

```text
{bankRootDirectory}
  cms-v2.db
  content-blocks/
    source/{ContentBlockId}/v{VersionNumber}.docx
    html/{ContentBlockId}/v{VersionNumber}.html
    text/{ContentBlockId}/v{VersionNumber}.txt
```

验证覆盖：

```text
路径落在 content-blocks/source|html|text
非法 ContentBlockId / VersionNumber 被拒绝
不生成旧 source / html 根目录
不访问 question-bank.db
本地文件存储可保存和读取 DOCX / HTML / TXT
Aspose 可创建空白 DOCX
Aspose 可生成 HTML 预览
Aspose 可提取 PlainText
创建空白内容块文档时同步创建元数据和文件资产
导入 DOCX 新版本时递增版本号并可切换当前版本
无效输入不创建文件资产
处理失败时清理半成品文件
```

不做：

- 不做本地 API。
- 不做前端。
- 不做 VSTO。
- 不做讲义整本生成。
- 不新增数据库表。
- 不新增迁移。

## 阶段 7：讲义 DOCX 生成链路

状态：Done

目标：

- 在阶段 6 的内容块 DOCX 能力基础上，生成完整讲义 Word 文件。
- 展开 HandoutVersionItem。
- 展开 SectionVariantItem。
- 展开 ContentBlockRelation。
- 解析跟随最新和锁定版本。
- 拼接多个内容块 DOCX。
- 记录 GeneratedFile 和版本清单。

需要完成：

- HandoutVersion 生成 Word。
- 内容块组合递归展开。
- 小节变体展开。
- 最小可用 DOCX 拼接。
- OutputTemplate 初步套用。
- GeneratedFile 写入。
- 生成失败记录策略。

已完成：

- Domain 扩展 `ICmsV2FileAssetPathProvider.GetGeneratedHandoutDocxPath`。
- Domain 新增 `IHandoutDocumentGenerator` 与 `HandoutDocumentSource`。
- Infrastructure 新增 `AsposeHandoutDocumentGenerator`。
- 生成路径固定为 `handouts/generated/{HandoutVersionId}/{yyyyMMddHHmmssfff}-{OutputFormId}-{SafeTitle}.docx`。
- Application 新增 `GenerateHandoutWordCommand`、`GeneratedHandoutFileResult`、`HandoutGenerationUseCases.GenerateHandoutWordAsync`。
- 支持从 `OutputForm` 查找 `HandoutVersion` 与 `OutputTemplate`。
- 支持展开 `HandoutVersionItem -> SectionVariantItem -> SectionItem / AtomicSectionItem -> ContentBlockRelation`。
- 支持 `FollowLatest` 与 `LockedVersion` 解析。
- `ContentBlockRelation` 生成时再次检测递归循环，最大展开深度固定为 10。
- 使用 Aspose 套用模板并按顺序拼接内容块 DOCX。
- 生成成功后写入 `GeneratedFile` 与 camelCase `VersionManifestJson`。
- 模板缺失、源 DOCX 缺失、当前版本缺失、锁定版本归属错误、循环引用、深度超限、非 Word 输出格式均抛 `CmsV2ApplicationException`。
- 失败时不写 `GeneratedFile`，并尽量删除本次生成的半成品 DOCX。

本阶段明确不做：

- API Controller。
- 前端。
- VSTO。
- PDF 输出。
- 变量替换。
- 学生版 / 教师版条件过滤。
- 新增数据库表或 EF migration。

## 阶段 8：本地 API

状态：Done

目标：

- 为浏览器管理端提供 V2 HTTP API。
- 不复用旧前端接口形状。
- 不兼容旧 CMS 表结构。

需要完成：

- 依赖注入组合根。
- DbContext 注册。
- 仓储注册。
- 文件资产服务注册。
- DOCX 处理服务注册。
- Application 用例注册。
- 内容块 API。
- Section API。
- SectionVariant API。
- Handout API。
- OutputTemplate / OutputForm API。
- TeachingNote API。

已完成：

- `WordSolution.CmsV2.Api` 使用 ASP.NET Core Minimal APIs。
- API 统一前缀为 `/api/cms-v2`。
- JSON 使用 camelCase，枚举使用字符串。
- 新增配置项 `CmsV2:BankRootDirectory`，默认指向 `E:\Desktop\题库中心-v2`。
- API 启动时创建 V2 根目录，并执行 EF migration 创建 / 更新 `cms-v2.db`。
- 注册 `CmsV2DbContext`、`ICmsV2UnitOfWork`、文件资产服务、Aspose DOCX 处理服务、讲义生成服务和现有 Application 用例。
- 增加统一异常处理：领域异常、应用异常和参数异常返回 400；端点内资源缺失返回 404；未知异常返回 500 ProblemDetails。
- 已暴露健康检查、枚举元数据、TeachingTopic、ContentBlock、Section、AtomicSection、SectionVariant、Handout、OutputTemplate、OutputForm、GeneratedFile、TeachingNote 的最小可用端点。
- 已支持内容块空白 DOCX 创建、DOCX 导入新版本、HTML 预览读取、DOCX 下载、讲义 Word 生成、GeneratedFile 查询、生成文件下载和版本清单读取。

本阶段明确不做：

- 前端。
- VSTO。
- 旧数据读取 / 迁移 / 兼容。
- 完整 PUT / PATCH / DELETE。
- PDF / WordAndPdf 输出。
- 变量替换。
- 学生版 / 教师版条件过滤。

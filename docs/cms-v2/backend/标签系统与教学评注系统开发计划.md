# CMS V2 标签系统与教学评注系统开发计划

本文档用于后续 Codex 执行线程拆分开发任务。它只规划后续实现阶段，本轮不做代码实现。

正式规格见：

```text
docs/cms-v2/backend/标签系统与教学评注系统开发文档.md
```

## 0. 总目标

在 CMS V2 中补齐两个独立能力：

```text
Tag
  自由标签，用于检索、筛选、选题。

TeachingNote
  轻量教学评注，用于记录教学观察、课堂经验、复盘想法。
```

开发总边界：

- 不修改 V1 后端。
- 不修改 `题库本地服务/wwwroot`。
- 不修改 `VSTO/`。
- 不修改 `Word本地文件操作核心库/`。
- 不新增 `TagRunner.*` 项目或命名空间。
- 后端只进入 `src-v2/WordSolution.CmsV2.*`。
- 前端只进入经确认后的 V2 前端工程。
- 前端只对接 `/api/cms-v2`。
- 不引入 V1 API 兼容层。

## 1. 阶段依赖

```text
Phase 1 标签后端
  -> Phase 2 标签前端
```

### 2.4 关键实现要求

领域规则：

- `Tag.Name` 非空。
- `NormalizedName = Name.Trim()`。
- 英文大小写不敏感。
- 中文按原文。
- 中间空格保留。
- `Tags.NormalizedName` 全局唯一。
- 创建时自动分配固定颜色 token。
- 第一版颜色 token 固定为 `tag-gray / tag-orange / tag-yellow / tag-green / tag-blue / tag-purple / tag-pink / tag-red`。
- 删除标签是归档，不物理删除。
- Archived 标签不允许新绑定。
- 恢复 Archived 标签时防止与 Active 标签冲突。

绑定规则：

- 第一版只允许 `ContentBlock / AtomicSection / Section`。
- `TagBinding(TagId, TargetType, TargetId)` 唯一。
- 一个 Tag 可以绑定多个对象。
- 一个对象可以绑定多个 Tag。
- `PUT /api/cms-v2/tag-bindings` 是针对单个目标对象替换标签列表，不影响这些 Tag 与其他对象的绑定。
- 第一版不实现 TagBinding 备注。
- 第一版不要求增量 add/remove 接口。

### 2.5 API 目标

```http
GET   /api/cms-v2/tags?keyword=xxx
POST  /api/cms-v2/tags
PATCH /api/cms-v2/tags/{tagId}
POST  /api/cms-v2/tags/{tagId}/archive
POST  /api/cms-v2/tags/{tagId}/restore
GET   /api/cms-v2/tag-bindings?targetType=ContentBlock&targetId=123
PUT   /api/cms-v2/tag-bindings
```

`ContentBlock` 搜索需支持多标签 AND，可扩展：

```http
GET /api/cms-v2/content-blocks?tagIds=1&tagIds=2
```

或新增：

```http
POST /api/cms-v2/content-blocks/search
```

- 不把标签绑定到 `AtomicSectionPanel`。
- 不把标签绑定到版本、讲义输出或生成文件。
- 不在业务代码中写死颜色值。
- 不物理删除 Tag。
- 不创建 V1 兼容接口。

### 2.7 测试要求

必须覆盖：

- 创建标签自动 Trim。
- 创建标签自动生成 `NormalizedName`。
- 标签名全局唯一。
- 英文大小写忽略。
- 中间空格保留。
- 创建标签自动分配颜色 token。
- Active 同名创建返回已有标签。
- Archived 同名创建返回业务错误。
- 改名防重复。
- 归档标签。
- 恢复标签。
- 恢复时防冲突。
- 给 `ContentBlock` 绑定多个标签。
- 给 `AtomicSection` 绑定标签。
- 给 `Section` 绑定标签。
- 同一对象同一标签不能重复绑定。
- 替换式保存标签绑定。
- 替换式保存不影响同一 Tag 与其他对象的绑定。
- Archived 标签不能新增绑定。
- 删除绑定不删除 Tag。
- ContentBlock 单标签筛选。
- ContentBlock 多标签 AND 筛选。
- 显式传 Archived tagId 时按已有绑定返回结果或按统一业务规则处理。

### 2.8 人工验收点

### 6.5 人工验收总表

标签：

- 创建标签。
- 重复创建同名 Active 标签返回已有标签。
- Archived 同名标签创建返回业务错误。
- 改名防重复。
- 归档后不在普通搜索候选出现。
- 已有 Archived 绑定继续弱化显示。
- 恢复时防同名冲突。
- 对 ContentBlock / AtomicSection / Section 设置多个标签。
- `PUT /tag-bindings` 只替换单个目标对象标签列表。
- ContentBlock 多标签 AND 筛选。

教学评注：

- 创建无标题评注。
- 未选择效果时保存 `null`。
- 创建时默认绑定当前 Inspector 对象。
- 一条评注支持多绑定。
- 一个对象支持多条评注。
- 搜索范围为 `Content`。
- 按 `NoteType / EffectLevel / OccurredAt / Target` 筛选。
- 默认按 `UpdatedTime` 倒序。
- 删除评注二次确认。
- 多绑定评注删除提示会从所有关联对象移除。
- 删除后 Binding 不残留。

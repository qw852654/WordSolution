# CMS V2 后端数据模型开发文档

本文档记录 CMS V2 后端数据模型的目标对象、对象职责、字段、关系、约束、数据库表结构命名和分层落点。

当前已完成范围：

- V2 后端项目骨架。
- Domain 层领域对象、枚举、领域异常和最小领域规则。
- Infrastructure 层全新 EF Core 10 + SQLite 表结构、`CmsV2DbContext`、实体配置和初始建库迁移。

当前未完成范围：

- 仓储接口与仓储实现。
- 应用用例、命令、查询、DTO。
- API Controller。
- 文件存储服务、DOCX 处理、HTML 预览、讲义生成。
- 前端。
- 旧数据迁移。

## 1. 分层落点


## 2. 数据库边界

V2 使用独立 SQLite 数据库：

```text
cms-v2.db
```

明确不做：

```text
不读取 question-bank.db
不修改 question-bank.db
不迁移旧业务数据
不建立旧 CMS 表结构兼容层
不实现旧数据导入工具
```

`CmsV2DatabasePaths.GetDatabasePath(bankRootDirectory)` 固定返回：

```text
{bankRootDirectory}/cms-v2.db
```

## 3. 全局建模原则

- 领域对象使用英文类名。
- 主键统一使用 `int Id`。
- SQLite 表主键为自增整数主键。
- 领域属性使用 `private set`。
- 公开构造函数负责建立最小有效状态。
- 为 EF materialization 保留私有无参构造函数。
- 核心对象默认只保存 `UpdatedTime`，不保存 `CreatedTime`。
- `GeneratedFile.GeneratedTime` 是业务事实，单独保留。
- `Difficulty` 只允许出现在 `ContentBlock`、`Section`、`SectionVariant`。
- `ContentBlockVersion` 不保存 `Difficulty`、`BlockType`、`QuestionType`。
- `TeachingNote` 独立建模，不归入 `ContentBlock`。
- 枚举在 EF Core 中按整数列存储。
- 删除行为默认使用 `Restrict`，避免误删内容资产。
- 多态引用只保存 `TargetType + TargetId`，不强行建立跨表外键。
- 跨聚合图递归循环检测留到 Application/Repository 阶段。

## 4. 表结构总览

V2 当前建立 17 张业务表：

```text

SectionVariants
```

## 5. 对象、字段、关系与约束

### TeachingTopic

职责：表示教学内容在知识体系中的位置，只负责主题树定位，不承载讲义正文。

表名：`TeachingTopics`

字段：

```text
Id
ParentId
Name
Description
SortOrder
Status
UpdatedTime
```

关系与约束：

- `ParentId` 可指向另一个 `TeachingTopic`。
- `TeachingTopic 1 - N Section`。
- `TeachingNote` 可以挂载到 `TeachingTopic`。
- 删除行为 `Restrict`。

### Section

职责：表示某个教学主题下的一套小节上帝版本内容池。

表名：`Sections`

字段：

```text
Id
TeachingTopicId
Title
Description
Type
Difficulty
Status
SortOrder
UpdatedTime
```

关系与约束：

- `TeachingTopicId` 指向 `TeachingTopics.Id`。
- `Section 1 - N SectionItem`。
- `Section 1 - N SectionVariant`。
- `Difficulty` 保留在 `Section`。
- 删除行为 `Restrict`。

### SectionItem

职责：表示某个 `ContentBlock` 或 `AtomicSection` 被放入 `Section` 的一次出现。

表名：`SectionItems`

字段：

```text
Id
SectionId
TargetType
TargetId
ReferenceMode
LockedContentBlockVersionId
TitleOverride
ParentItemId
SortOrder
SelectionLayer
TeachingUseOverride
Status
Note
UpdatedTime
```

关系与约束：

- `SectionId` 指向 `Sections.Id`。
- `ParentItemId` 可指向同表 `SectionItems.Id`。
- `TargetType` 只允许 `ContentBlock` 或 `AtomicSection`。
- `TargetType + TargetId` 是多态引用，不建立跨表外键。
- `TargetType = ContentBlock` 时允许 `FollowLatest` 或 `LockedVersion`。
- `TargetType = AtomicSection` 时只能使用 `FollowLatest`，且不能设置 `LockedContentBlockVersionId`。
- `ReferenceMode = LockedVersion` 时必须提供 `LockedContentBlockVersionId`。
- `LockedContentBlockVersionId` 指向 `ContentBlockVersions.Id`。
- `SectionItem` 不保存 `Difficulty`。
- 删除行为 `Restrict`。

### AtomicSection

职责：表示 Section 内部的最小讲解结构。它组织内容块，但自身不保存 DOCX 正文。

表名：`AtomicSections`

字段：

```text
Id
Title
Description
Type
Status
UpdatedTime
```

关系与约束：

- `AtomicSection` 只能通过 `SectionItem` 放入 `Section`。
- `AtomicSection` 内部只能放 `ContentBlock`。
- `AtomicSection` 不能被 `HandoutVersionItem` 直接引用。
- `AtomicSection` 不保存 `Difficulty`。

### AtomicSectionItem

职责：表示 `ContentBlock` 被放入 `AtomicSection` 的一次出现。

表名：`AtomicSectionItems`

字段：

```text
Id
AtomicSectionId
ContentBlockId
ReferenceMode
LockedContentBlockVersionId
TitleOverride
SortOrder
Note
UpdatedTime
```

关系与约束：

- `AtomicSectionId` 指向 `AtomicSections.Id`。
- `ContentBlockId` 指向 `ContentBlocks.Id`。
- 只能引用 `ContentBlock`，不提供 `AtomicSection` 目标入口。
- `ReferenceMode = LockedVersion` 时必须提供 `LockedContentBlockVersionId`。
- `LockedContentBlockVersionId` 指向 `ContentBlockVersions.Id`。
- 删除行为 `Restrict`。

### SectionVariant

职责：表示从 Section 上帝版本中选择内容形成的小节子版本。

表名：`SectionVariants`

字段：

```text
Id
SectionId
Title
Description
Type
Difficulty
Status
SortOrder
UpdatedTime
```

关系与约束：

- `SectionId` 指向 `Sections.Id`。
- `SectionVariant 1 - N SectionVariantItem`。
- `TeachingNote` 可以挂载到 `SectionVariant`。
- `Difficulty` 保留在 `SectionVariant`。
- 删除行为 `Restrict`。

### SectionVariantItem

职责：表示某个 `SectionVariant` 选择了哪个 `SectionItem`。

表名：`SectionVariantItems`

字段：

```text
Id
SectionVariantId
SectionItemId
SortOrder
Note
UpdatedTime
```

关系与约束：

- `SectionVariantId` 指向 `SectionVariants.Id`。
- `SectionItemId` 指向 `SectionItems.Id`。
- 只能选择 `SectionItem`，不直接选择 `ContentBlock` 或 `AtomicSection`。
- 不保存 `IsIncluded`；未出现在表中即表示未选入该子版本。
- `SectionVariantId + SectionItemId` 唯一。
- 删除行为 `Restrict`。

### ContentBlock

职责：系统核心可复用内容资产。

表名：`ContentBlocks`

字段：

```text
Id
Title
Summary
BlockType
Difficulty
QuestionType
Status
CurrentVersionId
UpdatedTime
```

关系与约束：

- `CurrentVersionId` 可指向 `ContentBlockVersions.Id`。
- `ContentBlock 1 - N ContentBlockVersion`。
- `QuestionType` 只对 `BlockType = Question` 有业务意义。
- `Difficulty` 保留在 `ContentBlock`。
- `ContentBlock` 不保存小节排序、讲义排序或输出形式。
- `TeachingNote` 不归入 `ContentBlock`，只通过 `TeachingNote.TargetType + TargetId` 挂载。
- 删除行为 `Restrict`。

### ContentBlockVersion

职责：保存某个 `ContentBlock` 的某一版正文。

表名：`ContentBlockVersions`

字段：

```text
Id
ContentBlockId
VersionNumber
DocxPath
HtmlPreviewPath
PlainText
IsCurrent
UpdatedTime
```

关系与约束：

- `ContentBlockId` 指向 `ContentBlocks.Id`。
- `ContentBlockId + VersionNumber` 唯一。
- 不保存 `Difficulty`。
- 不保存 `BlockType`。
- 不保存 `QuestionType`。
- 正文主来源是 `DocxPath` 指向的 DOCX 文件。
- `PlainText` 用于搜索和索引。
- 删除行为 `Restrict`。

### ContentBlockRelation

职责：表示 `ContentBlock` 直接包含另一个 `ContentBlock`。

表名：`ContentBlockRelations`

字段：

```text
Id
ParentBlockId
ChildBlockId
ReferenceMode
LockedContentBlockVersionId
TitleOverride
SortOrder
Note
UpdatedTime
```

关系与约束：

- `ParentBlockId` 指向 `ContentBlocks.Id`。
- `ChildBlockId` 指向 `ContentBlocks.Id`。
- `ParentBlockId` 不能等于 `ChildBlockId`。
- `ReferenceMode = LockedVersion` 时必须提供 `LockedContentBlockVersionId`。
- `LockedContentBlockVersionId` 指向 `ContentBlockVersions.Id`。
- 递归循环检测留到应用层/仓储阶段。
- 删除行为 `Restrict`。

### Handout

职责：表示一组相关讲义的总入口，不代表某一份可打印讲义。

表名：`Handouts`

字段：

```text
Id
Title
Description
Status
UpdatedTime
```

关系与约束：

- `Handout 1 - N HandoutVersion`。
- 删除行为 `Restrict`。

### HandoutVersion

职责：表示某一套具体讲义内容组合。

表名：`HandoutVersions`

字段：

```text
Id
HandoutId
Title
Description
Type
Status
SortOrder
UpdatedTime
```

关系与约束：

- `HandoutId` 指向 `Handouts.Id`。
- `HandoutVersion 1 - N HandoutVersionItem`。
- `HandoutVersion` 不保存 `Difficulty`。
- 基础版、提高版、一轮复习版属于 `HandoutVersion`。
- 学生版、教师版、PDF、Word 属于 `OutputForm`。
- 删除行为 `Restrict`。

### HandoutVersionItem

职责：表示 `HandoutVersion` 引用了哪些内容。

表名：`HandoutVersionItems`

字段：

```text
Id
HandoutVersionId
TargetType
TargetId
SortOrder
TitleOverride
Note
UpdatedTime
```

关系与约束：

- `HandoutVersionId` 指向 `HandoutVersions.Id`。
- `TargetType` 只允许 `SectionVariant` 或 `ContentBlock`。
- 不允许直接引用 `Section`。
- 不允许直接引用 `AtomicSection`。
- `TargetType + TargetId` 是多态引用，不建立跨表外键。
- 删除行为 `Restrict`。

### OutputTemplate

职责：表示 DOCX 输出模板，承载纸张、页眉页脚、样式等复杂排版。

表名：`OutputTemplates`

```text

Title
```

关系与约束：

- `OutputTemplate 1 - N OutputForm`。
- 删除行为 `Restrict`。

### OutputForm

职责：表示同一个 `HandoutVersion` 的一种输出形式。

表名：`OutputForms`

```text
Id
```

关系与约束：

- `HandoutVersionId` 指向 `HandoutVersions.Id`。
- `OutputTemplateId` 指向 `OutputTemplates.Id`。
- `OutputForm 1 - N GeneratedFile`。
- 删除行为 `Restrict`。

### GeneratedFile

职责：记录某一次实际生成出来的文件。

表名：`GeneratedFiles`

字段：

```text
Id
OutputFormId
FilePath
VersionManifestJson
GeneratedTime
```

关系与约束：

- `OutputFormId` 指向 `OutputForms.Id`。
- `GeneratedTime` 是业务事实，保留。
- 不保存 `UpdatedTime`。
- 不保存 `CreatedTime`。
- `VersionManifestJson` 记录本次生成实际使用的内容版本清单。
- 删除行为 `Restrict`。

### TeachingNote

职责：保存教师经验、讲解反思、修改建议和未来提醒。

表名：`TeachingNotes`

字段：

```text
Id
TargetType
TargetId
NoteType
Title
Content
Status
UpdatedTime
```

关系与约束：

- `TargetType + TargetId` 是多态引用，不建立跨表外键。
- 可挂载目标包括 `TeachingTopic`、`Section`、`SectionVariant`、`SectionItem`、`AtomicSection`、`ContentBlock`、`HandoutVersion`。
- `TeachingNote` 独立于 `ContentBlockVersion`。

## 6. 当前索引与唯一约束

关键唯一约束：

```text
ContentBlockVersions(ContentBlockId, VersionNumber) UNIQUE
SectionVariantItems(SectionVariantId, SectionItemId) UNIQUE
```

关键查询索引：

```text
Sections(TeachingTopicId, SortOrder)
SectionItems(SectionId, SortOrder)
SectionItems(TargetType, TargetId)
AtomicSectionItems(AtomicSectionId, SortOrder)
SectionVariants(SectionId, SortOrder)
SectionVariantItems(SectionVariantId, SortOrder)
ContentBlockVersions(ContentBlockId, IsCurrent)
ContentBlockRelations(ParentBlockId, SortOrder)
HandoutVersions(HandoutId, SortOrder)
HandoutVersionItems(HandoutVersionId, SortOrder)
HandoutVersionItems(TargetType, TargetId)
OutputForms(HandoutVersionId, SortOrder)
TeachingNotes(TargetType, TargetId)
```

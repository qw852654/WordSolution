# CMS V2 后端数据模型开发文档

本文档记录 CMS V2 后端数据模型的目标对象、字段、职责、关系、领域约束、分层落点和后续表结构命名方向。

当前阶段只完成 `Domain` 层领域对象，不包含 EF Core、SQLite 表结构、仓储、API、迁移或 Word/DOCX 文件处理。

## 1. 分层落点

```text
WordSolution.CmsV2.Domain
  Entities      领域实体
  Enums         领域枚举
  Exceptions    领域异常
  Rules         领域校验守卫

WordSolution.CmsV2.Application
  后续承载用例、命令、查询、引用分析和业务编排

WordSolution.CmsV2.Infrastructure
  后续承载 SQLite、文件存储、DOCX、HTML 预览、生成链路

WordSolution.CmsV2.Api
  后续承载本地 HTTP API 和依赖注入组合根
```

## 2. 全局建模原则

- 领域对象使用英文类名，保持 V2 新项目命名一致。
- 主键统一使用 `int Id`，由后续 SQLite/EF 生成。
- 领域实体属性使用 `private set`，通过构造函数建立最小有效状态。
- 核心对象默认只保存 `UpdatedTime`，不保存 `CreatedTime`。
- `GeneratedFile.GeneratedTime` 是实际生成文件的业务事实，单独保留。
- `Difficulty` 只允许出现在 `ContentBlock`、`Section`、`SectionVariant`。
- `ContentBlockVersion` 只表示正文版本，不保存难度、内容类型或题型。
- `TeachingNote` 独立建模，不归入 `ContentBlock`。
- 锁定内容块版本时必须提供 `LockedContentBlockVersionId`。

## 3. 领域对象

### TeachingTopic

职责：表示教学内容在知识体系中的位置，只负责定位，不承载讲义、小节版本或正文。

字段：

```text
Id
ParentId
Name
Description
SortOrder
Status
UpdatedTime
```

关系：

```text
TeachingTopic 1 - N Section
TeachingTopic 可自引用形成主题树
TeachingNote 可挂到 TeachingTopic
```

### Section

职责：表示某个教学主题下的一套小节上帝版本内容池。

字段：

```text
Id
TeachingTopicId
Title
Description
Type
Difficulty
Status
SortOrder
UpdatedTime
```

关系：

```text
TeachingTopic 1 - N Section
Section 1 - N SectionItem
Section 1 - N SectionVariant
TeachingNote 可挂到 Section
```

### SectionItem

职责：表示某个 `ContentBlock` 或 `AtomicSection` 被放入 `Section` 的一次出现。

字段：

```text
Id
SectionId
TargetType
TargetId
ReferenceMode
LockedContentBlockVersionId
TitleOverride
ParentItemId
SortOrder
SelectionLayer
TeachingUseOverride
Status
Note
UpdatedTime
```

约束：

```text
TargetType 只允许 ContentBlock、AtomicSection
TargetType = ContentBlock 时允许 FollowLatest / LockedVersion
ReferenceMode = LockedVersion 时必须提供 LockedContentBlockVersionId
TargetType = AtomicSection 时不允许设置锁定内容块版本
SectionItem 不保存 Difficulty
SectionItem 不直接指向 ContentBlockVersion
```

### AtomicSection

职责：表示 Section 内部的最小讲解结构。它组织内容块，但自身不保存 DOCX 正文。

字段：

```text
Id
Title
Description
Type
Status
UpdatedTime
```

约束：

```text
AtomicSection 只能通过 SectionItem 放入 Section
AtomicSection 内部只能放 ContentBlock
AtomicSection 不能被 HandoutVersionItem 直接引用
AtomicSection 不保存 Difficulty
```

### AtomicSectionItem

职责：表示 `ContentBlock` 被放入 `AtomicSection` 的一次出现。

字段：

```text
Id
AtomicSectionId
ContentBlockId
ReferenceMode
LockedContentBlockVersionId
TitleOverride
SortOrder
Note
UpdatedTime
```

约束：

```text
AtomicSectionItem 只能引用 ContentBlock
ReferenceMode = LockedVersion 时必须提供 LockedContentBlockVersionId
AtomicSectionItem 不提供 AtomicSection 目标入口
AtomicSectionItem 不保存 Difficulty
```

### SectionVariant

职责：表示从 Section 上帝版本中选择内容形成的小节子版本。

字段：

```text
Id
SectionId
Title
Description
Type
Difficulty
Status
SortOrder
UpdatedTime
```

关系：

```text
Section 1 - N SectionVariant
SectionVariant 1 - N SectionVariantItem
TeachingNote 可挂到 SectionVariant
```

### SectionVariantItem

职责：表示某个 `SectionVariant` 选择了哪个 `SectionItem`。

字段：

```text
Id
SectionVariantId
SectionItemId
SortOrder
Note
UpdatedTime
```

约束：

```text
不保存 IsIncluded
未出现在 SectionVariantItem 中即表示未选入该子版本
```

### ContentBlock

职责：系统核心可复用内容资产。

字段：

```text
Id
Title
Summary
BlockType
Difficulty
QuestionType
Status
CurrentVersionId
UpdatedTime
```

约束：

```text
QuestionType 只对 BlockType = Question 有意义
ContentBlock 不保存小节排序、讲义排序或输出形式
TeachingNote 不归入 ContentBlock
```

### ContentBlockVersion

职责：保存某个 ContentBlock 的某一版正文。

字段：

```text
Id
ContentBlockId
VersionNumber
DocxPath
HtmlPreviewPath
PlainText
IsCurrent
UpdatedTime
```

约束：

```text
不保存 Difficulty
不保存 BlockType
不保存 QuestionType
正文主来源是 DocxPath 指向的 DOCX 文件
PlainText 只用于搜索和索引
```

### ContentBlockRelation

职责：表示 ContentBlock 直接包含另一个 ContentBlock。

字段：

```text
Id
ParentBlockId
ChildBlockId
ReferenceMode
LockedContentBlockVersionId
TitleOverride
SortOrder
Note
UpdatedTime
```

约束：

```text
ReferenceMode = LockedVersion 时必须提供 LockedContentBlockVersionId
ParentBlockId 不能等于 ChildBlockId
递归循环检测留到应用层/仓储阶段
ContentBlockRelation 不保存教学用途
```

### Handout

职责：表示一组相关讲义的总入口，不代表某一份可打印讲义。

字段：

```text
Id
Title
Description
Status
UpdatedTime
```

关系：

```text
Handout 1 - N HandoutVersion
```

### HandoutVersion

职责：表示某一套具体讲义内容组合。

字段：

```text
Id
HandoutId
Title
Description
Type
Status
SortOrder
UpdatedTime
```

约束：

```text
HandoutVersion 不保存 Difficulty
基础版、提高版、一轮复习版属于 HandoutVersion
学生版、教师版、PDF、Word 属于 OutputForm
```

### HandoutVersionItem

职责：表示 HandoutVersion 引用了哪些内容。

字段：

```text
Id
HandoutVersionId
TargetType
TargetId
SortOrder
TitleOverride
Note
UpdatedTime
```

约束：

```text
TargetType 只允许 SectionVariant、ContentBlock
不允许直接引用 Section
不允许直接引用 AtomicSection
```

### OutputTemplate

职责：表示 DOCX 输出模板，承载纸张、页眉页脚、样式等复杂排版。

字段：

```text
Id
Title
Description
TemplateDocxPath
Status
UpdatedTime
```

### OutputForm

职责：表示同一个 HandoutVersion 的一种输出形式。

字段：

```text
Id
HandoutVersionId
OutputTemplateId
Title
Audience
OutputFormat
VisibilityMode
Status
SortOrder
UpdatedTime
```

### GeneratedFile

职责：记录某一次实际生成出来的文件。

字段：

```text
Id
OutputFormId
FilePath
VersionManifestJson
GeneratedTime
```

约束：

```text
GeneratedTime 是业务事实，可以保留
VersionManifestJson 记录本次生成实际使用的内容版本清单
```

### TeachingNote

职责：保存教师经验、讲解反思、修改建议和未来提醒。

字段：

```text
Id
TargetType
TargetId
NoteType
Title
Content
Status
UpdatedTime
```

可挂载目标：

```text
TeachingTopic
Section
SectionVariant
SectionItem
AtomicSection
ContentBlock
HandoutVersion
```

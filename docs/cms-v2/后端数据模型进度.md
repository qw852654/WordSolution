```text

SectionVariantItem 必须选择同一 Section 下的 SectionItem
HandoutVersionItem 只允许 SectionVariant / ContentBlock
HandoutVersionItem 拒绝直接引用 Section / AtomicSection
创建初始版本失败时事务回滚，不留下半成品 ContentBlock
```

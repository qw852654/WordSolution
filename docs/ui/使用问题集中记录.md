# 使用问题集中记录

本文件用于记录 CMS V2 在真实使用中暴露出来的体验问题、流程卡点和后续优化想法。它不是开发计划，也不是正式规格文档；具体进入开发前，再从这里筛选问题，合并到对应模块规格或总开发计划中。

## 记录原则

- 只记录真实使用中遇到的问题，不在这里展开完整方案。
- 每条问题尽量写清楚触发场景、当前表现、期望表现和影响范围。
- 可以记录已修复问题，方便后续回顾同类空态、加载态和边界态。
- 后续集中优化时，再按模块、严重程度和依赖关系整理优先级。
- 不为每个使用问题新建单独计划文档。

# UI.md

本文件定义讲义内容管理系统的 UI 方向。  
涉及页面、交互、布局、样式、前端组件时，必须先阅读本文件。

## 0. 阶段 5.6 UI 信息架构校准

当前系统已经推进到讲义内容管理与编排系统，不再是早期题库原型。它不是普通题库系统、普通 CRUD 后台、多人 SaaS 系统，也不是原生桌面软件。

系统定位为：

> 面向高中物理教学的本地讲义内容管理与编排系统。

核心特征：

- 浏览器页面是主要工作台。
- Word 是精细内容编辑器和最终讲义承载格式。
- `.docx` 内容块是长期保存的核心内容资产。
- 内容块可以是原子块，也可以是组合块。
- 小节用于组织一个教学主题下的讲解结构。
- 讲义用于组织一次具体输出材料。
- 系统重点不是“录入题目”，而是“复用内容块、编排小节、生成讲义，并在编排过程中快速补缺和修改”。
- 本系统是个人本地工作系统，不按多人协作、权限系统、云端 SaaS 方向设计。
- 系统主要运行在宽屏浏览器页面中。
- 在窄屏、Office 任务窗格或窗口宽度不足时，部分导航可以退化为 Drawer 抽屉面板。

本阶段文档校准的结论：下一步不应直接进入输出预设、条件内容、变量和 Word 模板。应先完成 UI 信息架构与开发文档校准，统一页面模式、对象概念和导航语义。

## 0.1 两类页面模式

系统 UI 不应被描述为所有页面都固定采用“左侧教学主题树 + 中间主区域 + 右侧上下文详情面板”。页面应区分两类模式：

1. 教学主题工作台模式。
2. 小节编辑器 / 讲义编辑器模式。

这两类模式的任务不同，布局也不同。

## 0.2 教学主题工作台模式

用户点击教学主题树中的某个主题时，例如 `功能关系 > 机械能守恒`，进入教学主题工作台。

布局：

```text
左侧：教学主题树
中间：主题工作台主区域
右侧：无常驻上下文面板
```

教学主题工作台不是编辑器页面，不需要右侧上下文详情面板。原因：

- 主题工作台的核心任务是快速选择工作对象。
- 用户此时最需要判断：进入小节编排，还是进入讲义编排。
- 右侧上下文窗口会增加视觉噪音和注意力消耗。
- 主题页不是编辑器，不需要常驻详情面板。

结论：主题工作台无右侧上下文面板。

选中教学主题后，中间主区域以两个水平排列的主卡片区为核心：

```text
┌──────────────────────────────────────────────┐
│ 主题：机械能守恒                              │
├──────────────────────┬───────────────────────┤
│ 小节编排              │ 讲义编排               │
│                      │                       │
│ [基础讲解版]          │ [机械能守恒专题讲义]    │
│ [提高班版]            │ [功能关系单元复习讲义]  │
│ [一轮复习版]          │ [+ 新建讲义]            │
│ [+ 新建小节方案]      │                       │
└──────────────────────┴───────────────────────┘
```

小节卡片区负责显示当前教学主题下的小节方案、快速进入小节编辑器、新建小节方案。

讲义卡片区负责显示当前教学主题下的关联讲义、快速进入讲义编辑器、新建讲义。

结论：小节和讲义作为两个水平主卡片区。

这两个卡片区是主题工作台的视觉主角。内容资源摘要、引用关系摘要、最近编辑记录、旧版本引用提醒等信息可以放在小节/讲义卡片下方作为次级区域，不应放成右侧常驻详情面板。

## 0.3 小节编辑器模式

用户从主题工作台点击某个小节方案后，进入小节编辑器。

布局：

```text
顶部：面包屑 / 当前小节方案 / 状态
左侧窄栏：折叠后的教学主题定位
左侧主栏：小节结构树
中间：小节展开内容区
右侧：当前选中块详情面板
```

进入编辑器后，教学主题树默认折叠，只保留窄栏或顶部面包屑中的当前位置提示。左侧主栏显示当前小节自己的结构树，而不是完整教学主题树。

小节结构树示例：

```text
小节：机械能守恒 - 基础讲解版
- 知识点
- 例题组
  - 例题 1
  - 例题 2
- 练习
- 下级模型
  - 竖直圆轨道
  - 杆模型
  - 球模型
```

点击小节结构树中的节点时：

1. 中间内容区滚动到对应内容块。
2. 对应内容块高亮。
3. 右侧详情面板显示该内容块详情、预览、Word 编辑入口、版本、引用关系。

小节结构树负责“快速预览整体结构”和“定位中间内容”，不是教学主题树。

小节编辑器回答的问题是：“这个教学主题应该怎么讲？”

操作语义：

- 新增内容块。
- 插入已有内容块。
- 调整内容块顺序。
- 移除小节中的引用。
- 在 Word 中编辑源内容块。
- 查看小节整体预览。

这些操作修改的是 `Section` 或 `SectionItem`。

## 0.4 讲义编辑器模式

用户从主题工作台点击某份讲义后，进入讲义编辑器。

布局：

```text
顶部：面包屑 / 当前讲义 / 状态
左侧窄栏：折叠后的教学主题定位
左侧主栏：讲义结构树
中间：讲义展开内容区
右侧：当前选中节点详情面板
```

讲义结构树示例：

```text
讲义：机械能守恒专题讲义
- 导入
- 机械能守恒基础小节
  - 知识点
  - 例题组
  - 练习
- 竖直圆轨道模型
- 课堂练习
```

点击讲义结构树中的节点时：

1. 中间内容区滚动到对应展开内容。
2. 对应内容块或小节节点高亮。
3. 右侧详情面板显示来源、引用方式、版本状态、预览和 Word 编辑入口。

讲义编辑器回答的问题是：“这份讲义应该怎么输出？”

操作语义：

- 添加小节。
- 添加内容块。
- 添加组合内容块。
- 调整讲义输出顺序。
- 移除讲义引用。
- 生成 Word 讲义。

这些操作修改的是 `Handout` 或 `HandoutItem`。调整讲义结构不能反向修改源小节结构。

## 0.5 两类树

### teaching-topic-nav 教学主题导航树

职责：

- 定位教学主题。
- 在主题工作台中作为主要左侧导航。
- 在编辑器页面中折叠为窄栏或面包屑入口。
- 不承载小节内部结构。
- 不承载讲义内部结构。
- 不承载版本记录。
- 不承载讲义生成记录。

示例节点：

- 功能关系
- 机械能守恒
- 竖直圆轨道
- 杆模型
- 球模型

### object-outline-tree 当前对象结构树

职责：

- 在小节编辑器中显示小节结构。
- 在讲义编辑器中显示讲义结构。
- 用于快速预览当前对象整体结构。
- 用于点击定位中间展开内容。
- 与中间内容区和右侧详情面板联动。

组件样式可以复用，但业务语义不能混用。不要再把教学主题树、小节结构树、讲义结构树全部描述成同一个东西。

## 0.6 UI 中必须区分的核心概念

### TeachingTopic 教学主题

教学主题表示教学内容在知识结构中的位置，例如功能关系、机械能守恒、竖直圆轨道、杆模型、球模型。教学主题的职责是定位，不直接承载小节方案、讲义方案、内容块版本、讲义版本或生成记录。

### ContentBlock 内容块

内容块是可复用内容资产，可以是知识点、例题、练习、方法总结、易错点、普通说明、题目或组合块。内容块可以被小节引用，也可以被讲义直接引用。

### Section 小节

小节回答的问题是：“这个教学主题应该怎么讲？”小节是教学组织单元，不是最终输出材料。小节内部按顺序引用内容块。

### SectionPlan 小节方案

小节方案是目标概念。同一个教学主题下，未来可能存在多个小节方案，例如基础讲解版、提高班版、一轮复习版、模型专题版。这些是不同教学用途的并列方案，不是历史版本。当前阶段如果暂时用 `Section` 承载这类概念，应视为阶段性映射。

### Handout 讲义

讲义回答的问题是：“这份材料应该怎么输出？”讲义可以引用小节、内容块、组合内容块。讲义不是教学主题，也不是小节。

### HandoutPlan 讲义方案

讲义方案是目标概念。同一个教学主题下，未来可能关联多份讲义，例如机械能守恒专题讲义、功能关系单元复习讲义、圆轨道专项讲义。这些是不同输出用途的讲义方案，不应挂进教学主题树当作教学主题节点。当前阶段如果暂时用 `Handout` 承载这类概念，应视为阶段性映射。

### Variant 方案/变体 与 Version 版本

`Variant` 是不同用途的并列对象，例如基础讲解版、提高班版、一轮复习版。

`Version` 是同一个对象的历史记录，例如内容块 v1/v2/v3、讲义生成记录、未来的讲义快照。

版本不应该作为主导航节点显示。

## 1. UI 总目标

本系统不是展示型网站，而是高频使用的本地管理后台。

核心体验目标：

- 自然流畅。
- 主次分明。
- 快速编排。
- 快速补缺。
- 快速修改。
- 能在编排过程中直接处理内容问题。
- 减少页面跳转。
- 减少“先记下来以后再改”的断裂感。

核心工作区：

1. 小节编排
2. 讲义编排

辅助工作区：

1. 内容资源库
2. 标签筛选
3. 内容块详情
4. Word 编辑会话状态
5. 引用影响范围
6. 版本与状态维护

## 2. 核心对象的 UI 表达

### 2.1 内容块 ContentBlock

内容块是最小可复用资产。

常见类型：

- 知识点
- 例题
- 练习
- 方法总结
- 易错点
- 普通说明
- 题目

UI 表达：

- 内容块应该显示为卡片。
- 卡片中必须包含标题、类型、状态、标签摘要、版本状态。
- 卡片可以被插入小节或讲义。
- 卡片可以被 Word 打开编辑。
- 卡片可以展示 HTML 预览。
- 卡片不应该只是一行表格数据。

### 2.2 组合内容块

组合内容块本质是“引用其他内容块的结构”。

UI 表达：

- 外层仍是卡片。
- 内部显示子块列表或子树。
- 子块有顺序。
- 子块可以上移、下移、移除。
- 子块可以继续展开。
- 必须能看出它不是复制内容，而是引用内容。

### 2.3 小节 Section

小节是基本教学组织单元。

小节可能属于某个章节节点，也可能继续包含更细的物理模型或子结构。

例如：

```text
功能关系
  机械能守恒
    竖直圆轨道
    杆模型
    球模型

# UI.md

本文件定义讲义内容管理系统的 UI 方向。  
涉及页面、交互、布局、样式、前端组件时，必须先阅读本文件。

## 1. UI 总目标

本系统不是展示型网站，而是高频使用的本地管理后台。

核心体验目标：

- 自然流畅。
- 主次分明。
- 快速编排。
- 快速补缺。
- 快速修改。
- 能在编排过程中直接处理内容问题。
- 减少页面跳转。
- 减少“先记下来以后再改”的断裂感。

核心工作区：

1. 小节编排
2. 讲义编排

辅助工作区：

1. 内容资源库
2. 标签筛选
3. 内容块详情
4. Word 编辑会话状态
5. 引用影响范围
6. 版本与状态维护

## 2. 核心对象的 UI 表达

### 2.1 内容块 ContentBlock

内容块是最小可复用资产。

常见类型：

- 知识点
- 例题
- 练习
- 方法总结
- 易错点
- 普通说明
- 题目

UI 表达：

- 内容块应该显示为卡片。
- 卡片中必须包含标题、类型、状态、标签摘要、版本状态。
- 卡片可以被插入小节或讲义。
- 卡片可以被 Word 打开编辑。
- 卡片可以展示 HTML 预览。
- 卡片不应该只是一行表格数据。

### 2.2 组合内容块

组合内容块本质是“引用其他内容块的结构”。

UI 表达：

- 外层仍是卡片。
- 内部显示子块列表或子树。
- 子块有顺序。
- 子块可以上移、下移、移除。
- 子块可以继续展开。
- 必须能看出它不是复制内容，而是引用内容。

### 2.3 小节 Section

小节是基本教学组织单元。

小节可能属于某个章节节点，也可能继续包含更细的物理模型或子结构。

# 内容管理系统升级路线

## 当前共识

- 目标是把现有题库系统升级为讲义内容管理系统。
- 系统以 `ContentBlock` 为基本内容资产，以 `Section` 作为教学组织单元，以 `Handout` 作为最终输出单元。
- 浏览器管理端负责内容管理、审查、引用关系、小节编排、讲义编排和输出设置。
- Word 继续作为精细编辑器和最终讲义承载格式。
- 内容块主资产继续保存为 Word 文件，图片、公式、表格、排版都封装在 `.docx` 中，不单独建设媒体资源库。
- 内容块分为原子块和组合块；组合块保存对子内容块的有序引用，不复制子块正文。
- 内容块允许多层嵌套，但必须禁止循环嵌套，并默认限制最大展开深度。
- 内容块的章节归属、难度、来源和原题标签统一纳入标签体系，通过内容块-标签关系挂接。
- 内容块正文编辑不以前端上传 `.docx` 为主流程，优先通过浏览器发起 Word 本地编辑会话。
- Word 本地编辑会话在 Word 文档关闭后再同步为内容块新版本，避免编辑过程中反复保存产生碎版本。
- `E:\Desktop\题库中心` 暂时保持硬编码，等系统可用后再改为配置。

## 项目边界

- 主线项目：
  - `题库核心`
  - `题库应用`
  - `题库基础设施`
  - `题库本地服务`
  - `question-bank-office-addin`
  - 后续新增浏览器管理端

- 保留但不纳入 CMS 主架构：
  - `VSTO`
  - `Word本地文件操作核心库`

这两个项目后续仍会持续使用，但定位为本地 Word 文件辅助处理能力，不作为新内容管理系统的核心架构组成部分。

- 暂时搁置或仅按需处理：
  - `Core.QuestionBank`
  - `TagRunner`
  - `tools/旧题库迁移工具`

补充约束：
- `Core.QuestionBank` 和 `TagRunner` 只作为历史代码参考，不接收新主线功能。
- 新功能默认进入 `题库核心`、`题库应用`、`题库基础设施`、`题库本地服务` 或 `question-bank-office-addin`。
- 不新增 `TagRunner.*` 项目、命名空间或目录。

## 目标模块

以下是总目标清单，不代表当前阶段都要实现。每次开发只按“开发阶段”中对应阶段范围修改，避免提前实现后续能力。

- 内容块模块
  - 知识点
  - 例题
  - 练习
  - 方法总结
  - 易错点
  - 普通说明
  - 题目
  - 原子块
  - 组合块
  - 子块有序引用
  - 循环嵌套检测
  - Word 本地编辑会话
  - 分类标签挂接

- 小节模块
  - 小节作为基本教学单元。
  - 小节内部按顺序引用内容块。
  - 典型结构为：知识点 -> 例题 -> 练习。

- 讲义模块
  - 讲义引用小节或单个内容块。
  - 支持草稿、发布快照、历史版本。

- 版本模块
  - 内容块版本。
  - 讲义发布基线。
  - 支持锁定版本和跟随最新版。

- 引用关系模块
  - 查看内容块被哪些小节、讲义引用。
  - 修改共享内容前提示影响范围。

- 输出模块
  - Word 模板。
  - 学生版、教师版、解析版。
  - 条件内容。
  - 变量填充。

- 质量维护模块
  - 内容状态。
  - 健康检查。
  - 全文搜索。
  - 按章节、难度、来源、附加标签维护内容归属。

## 开发阶段

### 阶段 0：项目主线整理

- 明确主线项目和辅助项目边界。
- 暂不改 `E:\Desktop\题库中心` 硬编码路径。
- `VSTO` 和 `Word本地文件操作核心库` 保留为本地文件辅助处理项目。
- 为后续内容块模块建立必要的测试基线。

### 阶段 1：内容块底座

- 新增内容块领域模型。
- 新增内容块版本模型。
- 新增内容块文件存储。
- 新增内容块 HTML 预览生成。
- 新增内容块纯文本提取。
- 新增内容块 API：
  - 新建内容块
  - 上传或保存内容块 `.docx`
  - 获取内容块预览
  - 获取内容块详情
  - 列表查询

阶段边界：

- 阶段 1 只建立最小内容块底座和可追溯的版本记录。
- 不实现组合嵌套、小节、讲义和讲义快照发布。

### 阶段 1.5：内容块嵌套与组合结构

- 新增内容块结构类型：
  - 原子块
  - 组合块
- 新增内容块子项模型。
- 支持组合块添加子内容块。
- 支持子块排序。
- 支持子块引用版本模式：
  - 跟随最新版本
  - 锁定指定版本
- 支持获取内容块结构树。
- 添加子块时检测循环嵌套。
- 限制最大嵌套深度，初始建议为 10 层。

阶段边界：

- 本阶段仍只做后端底座，不做完整浏览器页面。
- 不做小节、讲义和发布快照。
- 组合块不复制子块正文，预览和导出时递归展开引用。

### 阶段 2：浏览器内容库

- 新增内容块列表页面。
- 新增内容块详情页面。
- 支持新建内容块。
- 支持从网页发起 Word 本地编辑会话。
- 支持查看 HTML 预览。
- 支持内容状态：草稿、待审查、可复用、需修订、已废弃。
- 支持标题和正文搜索。

阶段边界：

- 浏览器管理端优先复用现有 `question-bank-office-addin` 构建链路或 `题库本地服务/wwwroot` 静态托管方式。
- 没有明确决策前，不新增独立前端项目。

### 阶段 2.1：Word 本地编辑会话

- 新建内容块并立即在 Word 中编辑。
- 打开已有内容块当前版本到 Word 编辑。
- 后端创建 `temp/edit-sessions/{sessionId}/content.docx`。
- 新建内容块时生成空白 `.docx`。
- 编辑已有内容块时复制当前版本 `.docx`。
- 使用 Windows 文件关联打开 `.docx`，不硬编码 `WINWORD.EXE` 路径。
- 不依赖 Word 进程退出，改用锁文件消失、文件可读和文件稳定性判断文档已关闭。
- Word 文档关闭后，若文件 hash 变化，自动生成内容块新版本。
- 若 hash 无变化，标记会话为“无变化”，不生成新版本。
- 提供手动同步接口作为兜底。
- 提供取消会话接口。

阶段边界：

- 第一版会话保存在内存中，不建 SQLite 会话表。
- 暂不修改 CORS，不加 token 或来源限制。
- 不做 WebDAV。
- 不做前端上传 `.docx`。
- 不做 Word 加载项深度集成。

### 阶段 2.2：浏览器内容库最小可用页

- 在 `题库本地服务/wwwroot/cms.html` 提供第一版内容库页面。
- 支持内容块列表。
- 支持按类型、状态、关键词筛选。
- 支持内容块详情摘要。
- 支持 HTML 预览。
- 支持新建内容块并发起 Word 本地编辑会话。
- 支持打开已有内容块到 Word 编辑。
- 支持编辑会话状态轮询。
- 支持手动同步和取消会话。

阶段边界：

- 不做小节、讲义和引用影响分析。
- 不做独立前端项目。
- 不做前端上传 `.docx`。

### 阶段 2.3：组合块子块管理与结构树可视化

- 详情页新增组合结构区。
- 组合块显示子块列表和结构树。
- 支持从已有内容块添加子块。
- 支持子块角色。
- 支持引用模式：
  - 跟随最新
  - 锁定当前版本
- 支持子块上移、下移和移除引用。
- 原子块显示为不可嵌套。
- 添加子块失败时显示后端校验错误，例如循环嵌套和深度超限。

阶段边界：

- 子块管理仍基于内容块，不引入小节模型。
- 组合块预览和导出递归拼接后续再做。

### 阶段 2.4：详情、版本与状态管理完善

- 新增内容块元数据保存接口：
  - `PUT /api/题库实例/{题库键}/内容块/{id}`
- 网页详情页支持编辑：
  - 标题
  - 摘要
  - 类型
  - 状态
  - 结构类型
- 元数据保存不生成 Word 内容版本。
- 若组合块已有子块，禁止改为原子块或关闭子块能力。
- 网页详情页显示内容块版本列表。
- 版本列表标记当前版本。

阶段边界：

- 不支持切换当前版本。
- 不支持查看历史版本预览。
- 不支持版本差异对比。

### 阶段 2.5：内容块分类与标签接入

- 新增内容块标签关系表：
  - `ContentBlockTags`
  - `ContentBlockId`
  - `TagId`
- 内容块复用现有标签体系：
  - 章节
  - 做题方法
  - 难度
  - 附加标签
  - 年份
  - 来源
- 新增内容块标签 API：
  - `GET /api/题库实例/{题库键}/内容块/{id}/标签`
  - `PUT /api/题库实例/{题库键}/内容块/{id}/标签`
- 内容块列表查询支持 `标签ID列表` 筛选。
- 保持标签规则：
  - 难度、年份、来源单选。
  - 待整理标签不进入正式内容块流程。
  - 已被内容块引用的标签不能直接删除。
- 内容库页面支持：
  - 按标签筛选内容块。
  - 在详情页编辑内容块的章节、难度、来源等标签。

阶段边界：

- 本阶段不做完整标签管理页面。
- 本阶段不新增小节模型。
- 本阶段不改变内容块 `.docx` 存储策略。
- 本阶段先支持单标签列表筛选，详情页标签编辑支持多种类保存。

### 阶段 5：引用关系与版本

- 内容块、组合块、小节、讲义之间的引用位置统计。
- 修改共享内容时显示影响范围。
- 内容块保存为新版本后的影响分析。
- 小节和讲义支持：
  - 跟随最新版本
  - 锁定当前版本
- 支持讲义发布快照。

当前落地范围：

- 新增应用层引用关系分析器，不新增冗余引用关系表。
- 从现有结构动态推导引用关系：
  - `ContentBlockChildren`
  - `SectionItems`
  - `HandoutItems`
- 支持内容块影响范围分析：
  - 被哪些组合块直接或间接包含。
  - 被哪些小节直接或间接引用。
  - 被哪些讲义直接引用，或通过小节间接引用。
  - 引用链路展示，例如：`讲义 > 小节 > 组合块 > 内容块`。
- 支持旧版本锁定引用审查：
  - 组合块子项锁定旧内容块版本。
  - 小节项锁定旧内容块版本。
  - 讲义项锁定旧内容块版本。
- 新增引用关系 API：
  - `GET /api/题库实例/{题库键}/内容块/{id}/引用`
  - `GET /api/题库实例/{题库键}/引用关系/旧版本引用`
- 内容库页面新增“影响范围”区域。
- 新增浏览器页面：
  - `http://localhost:5282/references.html`

阶段边界：

- 本阶段先做只读分析，不做一键批量更新引用到最新版。
- 本阶段不落地正式讲义发布快照，继续保留阶段 4 的生成记录和版本清单。
- 本阶段不新增引用关系缓存表，避免缓存与真实结构不一致。

### 阶段 5.5：讲义编排主树

目标：

- 让讲义编排器从“顶层卡片列表 + 辅助树”改为“树就是主编排界面”。

范围：

```text
共享树组件
讲义结构树接口
讲义主编排树
小节项展开
组合内容块递归展开
树节点选中
树节点上移/下移/移除
树节点添加小节/内容块/子内容块
节点详情预览
上下文 Word 编辑
编辑会话状态轮询
同步后刷新树和预览
```

交互说明：

- 讲义编排器不再把顶层项目卡片作为主操作区。
- 选择讲义后调用 `GET /api/题库实例/{题库键}/讲义/{id}/结构树`，直接渲染完整编排树。
- 树默认展开，节点可收起，便于审查大纲层级。
- 讲义根节点可添加小节或内容块。
- 小节节点可添加内容块、上移、下移、移除，并在右侧编辑小节信息。
- 内容块节点可上移、下移、移除，并可在 Word 中编辑。
- 组合内容块节点额外支持添加子内容块。
- 点击任意内容块节点，右侧“上下文编辑”区域显示该内容块摘要、类型、状态、版本和 HTML 预览。
- 点击“在 Word 中编辑”会创建已有内容块编辑会话，并打开该内容块的 `.docx`。
- 用户关闭 Word 后，后台同步新版本，前端轮询到完成状态后刷新树、预览和当前内容块信息。

阶段边界：

- 本阶段只编辑被引用的源内容块，不生成讲义内局部副本。
- 删除操作只删除引用关系，不删除源小节或源内容块。
- 本阶段不做树节点拖拽排序；排序使用树节点上的上移、下移按钮完成。
- 本阶段不做一键替换旧版本引用，仍由引用审查阶段提供只读提示。

### 阶段 6：输出预设、条件内容、变量

- 支持学生版、教师版、解析版。
- 支持条件标签：
  - 基础班
  - 提高班
  - 一轮复习
  - 专题突破
- 支持变量：
  - 讲义标题
  - 班级
  - 教师
  - 日期
- 支持 Word 模板：
  - 普通讲义
  - 课堂练习
  - 答案解析

### 阶段 7：健康检查与搜索增强

- 检查无引用内容块。
- 检查已废弃但仍被引用的内容块。
- 检查缺少 `.docx` 文件的内容块。
- 检查缺少 HTML 预览的内容块。
- 检查讲义引用旧版本。
- 检查内容块缺少标签或状态。
- 记录讲义生成失败信息。
- 增强正文、标签、小节、引用状态、内容状态搜索。

### 阶段 8：Word 深度集成

- 从网页点击“在 Word 中编辑”。
- Word 加载项打开内容块。
- 编辑后保存回系统。
- 用内容控件标记 `内容块ID=xxx`。
- 从当前选区创建内容块。
- 更新已有内容块。
- 插入内容块到当前 Word 文档。

阶段边界：

- 阶段 0-4 中，Word 加载项只保持现有题目录入、插入和预览相关能力可用。
- 上述内容块编辑回存能力不应在早期任务中提前实现。

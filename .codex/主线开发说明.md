# 主线开发说明

## CMS 主线构建

当前 CMS 主线使用 solution filter 构建，避免被保留的 VSTO / Office Interop 辅助项目阻塞。

```powershell
dotnet build WordSolution.Cms.slnf -v:minimal
```

前端 Office 加载项仍在独立目录构建：

```powershell
cd question-bank-office-addin
npm run build
```

## 当前推进顺序记录

阶段 1：内容块底座已完成。

阶段 1.5：内容块嵌套与组合结构已完成，能力包括：

- 内容块区分原子块和组合块。
- 题目默认作为原子块，不允许嵌套子块。
- 组合块通过有序引用包含子内容块，不复制子块正文。
- 子块引用支持跟随最新版本和锁定指定版本。
- 添加子块时必须检测循环嵌套。
- 默认限制最大嵌套深度，初始建议为 10 层。

阶段 2.1：Word 本地编辑会话已完成。

阶段 2.1 的目标：

- 浏览器不上传 `.docx`，而是发起本地 Word 编辑会话。
- 后端创建 `temp/edit-sessions/{sessionId}/content.docx`。
- 新建内容块时生成空白 Word 文件。
- 编辑已有内容块时复制当前版本 Word 文件。
- 后端使用系统文件关联打开 `.docx`。
- 用户关闭 Word 文档后，后端再同步为内容块新版本。
- 同步判断以 Word 锁文件消失、文件可读、文件稳定和 hash 变化为准。
- 暂不修改 CORS，不加 token，不做 WebDAV，不做前端上传 `.docx`。

阶段 2.2：浏览器内容库最小可用页已完成，入口为：

```text
http://localhost:5282/cms.html
```

当前页面能力：

- 内容块列表。
- 类型、状态、关键词筛选。
- 内容块详情摘要。
- HTML 预览。
- 新建内容块并发起 Word 编辑会话。
- 打开已有内容块到 Word 编辑。
- 编辑会话状态轮询。
- 手动同步和取消会话。

阶段 2.3：组合块子块管理与结构树可视化已完成，能力包括：

- 详情页显示组合结构。
- 组合块显示子块列表和递归结构树。
- 可从已有内容块添加子块。
- 添加子块时可设置角色。
- 添加子块时可选择跟随最新版本或锁定当前版本。
- 支持上移、下移和移除子块引用。
- 原子块显示为不可嵌套。

阶段 2.4：详情、版本与状态管理完善已完成，能力包括：

- 新增内容块元数据保存接口：`PUT /api/题库实例/{题库键}/内容块/{id}`。
- 网页详情页可编辑标题、摘要、类型、状态和结构类型。
- 元数据保存不生成 Word 内容版本。
- 网页详情页显示内容块版本列表。
- Word 同步产生的新版本能在版本列表中看到。

阶段 2.5：内容块分类与标签接入已完成，能力包括：

- 新增内容块标签关系表 `ContentBlockTags`。
- 内容块可挂接现有标签体系中的章节、难度、来源、附加标签等。
- 内容块列表支持按 `标签ID列表` 查询。
- 网页侧栏支持按标签筛选内容块。
- 网页详情页支持编辑内容块分类标签。
- 标签删除会检查是否已被内容块引用。

阶段 3：小节编辑器已完成，能力包括：

- 新增小节模型 `Sections`。
- 新增小节项模型 `SectionItems`。
- 小节可挂接章节标签。
- 小节内可添加已有内容块。
- 小节项支持跟随最新版本和锁定当前版本。
- 支持小节项上移、下移和移除引用。
- 支持小节整体 HTML 预览。
- 新增浏览器入口：`http://localhost:5282/sections.html`。

阶段 4：讲义编排与 Word 生成已完成第一版，能力包括：

- 新增讲义模型 `Handouts`。
- 新增讲义项模型 `HandoutItems`。
- 新增讲义生成记录模型 `HandoutGenerations`。
- 讲义可添加小节，也可直接添加内容块。
- 直接添加内容块时支持跟随最新版本或锁定当前版本。
- 讲义引用小节时，生成 Word 会展开小节项。
- 讲义引用组合内容块时，生成 Word 会递归展开子块。
- 支持讲义项上移、下移和移除引用。
- 支持用 Aspose 合并内容块 `.docx` 生成讲义 Word 文件。
- 生成文件保存到 `handouts/generated/{讲义ID}`。
- 生成记录可在浏览器下载。
- 新增浏览器入口：`http://localhost:5282/handouts.html`。

阶段 5：引用关系与版本影响分析已完成第一版，能力包括：

- 新增应用层 `引用关系分析器`。
- 内容块详情可查询影响范围：`GET /api/题库实例/{题库键}/内容块/{id}/引用`。
- 支持统计内容块被哪些组合块、小节、讲义引用。
- 支持显示完整引用链，例如：讲义 -> 小节 -> 组合块 -> 内容块。
- 支持识别锁定旧版本的引用。
- 新增全局旧版本引用审查：`GET /api/题库实例/{题库键}/引用关系/旧版本引用`。
- 内容库页面新增“影响范围”区域。
- 新增浏览器入口：`http://localhost:5282/references.html`。

阶段 5 当前边界：

- 先做只读分析，不自动批量修改引用。
- 正式讲义发布快照仍后置，当前继续使用阶段 4 的生成记录和版本清单。

阶段 5.5：讲义编排主树已完成，能力包括：

- 新增前端共享树组件 `shared-tree.css` / `shared-tree.js`。
- 新增讲义结构树接口：`GET /api/题库实例/{题库键}/讲义/{id}/结构树`。
- 讲义编排器以树作为主操作界面，根节点为当前讲义。
- 讲义结构树一次性展开“讲义项 -> 小节项 -> 组合内容块子块”。
- 树节点支持展开、收起、选中和复用样式，后续可用于小节、引用审查等页面。
- 树节点可直接执行上移、下移、移除、添加小节、添加内容块、添加子内容块。
- 小节节点可在右侧网页面板中编辑标题、摘要和状态。
- 选中内容块后，右侧可查看该内容块摘要和 HTML 预览。
- 可从讲义编排上下文直接唤起 Word 编辑源内容块。
- Word 关闭并同步后，自动刷新讲义层级树、内容块预览和版本状态。
- 内容库原有组合结构树已切换为共享树样式。

阶段 5.5 当前边界：

- 本阶段只编辑“源内容块”，不在讲义中产生局部副本。
- 删除操作只删除引用关系，不删除源小节或源内容块。
- 暂不做树节点拖拽排序，先使用树节点上的上移、下移按钮。

阶段 5.6：UI 信息架构与开发文档校准为当前新增阶段。

阶段 5.6 的目标：

- 统一系统定位：面向高中物理教学的本地讲义内容管理与编排系统。
- 区分教学主题、小节方案、讲义方案、内容块和版本。
- 明确教学主题工作台、小节编辑器、讲义编辑器三类页面模式。
- 明确教学主题树和当前对象结构树的区别。
- 明确主题工作台无右侧上下文面板。
- 明确主题工作台中小节和讲义两个水平主卡片区。
- 明确进入小节编辑器或讲义编辑器后，教学主题树默认折叠，左侧主栏显示当前对象结构树。
- 明确当前 UI 目标形态与现有静态页面入口之间可能存在差异。

阶段 5.6 边界：

- 只做开发文档校准，不写代码。
- 不修改数据库。
- 不修改后端 API。
- 不修改前端页面。
- 不引入前端框架。
- 不实现 route。
- 不实现 `TeachingTopic`、`SectionPlan`、`HandoutPlan` 模型。

当前差异记录：

- 当前仓库已有 `cms.html`、`sections.html`、`handouts.html`、`references.html` 等页面入口。
- 目标形态中存在 `/app/topics/:topicId`、`/app/section-plans/:sectionPlanId`、`/app/handouts/:handoutId` 等 route 语义，但当前不要求实现。
- 当前已有 `Section` 和 `Handout`，但 `SectionPlan` 和 `HandoutPlan` 仍是目标概念。
- 当前讲义编排主树已完成第一版，但 UI 信息架构仍需统一。

下一步先完成阶段 5.6，再决定是否进入阶段 6：输出预设、条件内容、变量和 Word 模板。
